# The window

Four panes around the stage:

| Pane | Where | What it is |
| --- | --- | --- |
| **Library** | Left | Photos and videos in this project |
| **Preview** | Center | The movie, plus Play / scrub |
| **Inspector** | Right | Style, Intro, Motion, Audio, Format |
| **Timeline** | Bottom | Photo lane + music lane |

![Inspector tabs: Style, Intro, Motion, Audio, Format](../.gitbook/assets/inspector-tabs.png)

## Toolbar

On the right:

![Essential / Studio, Export, Help, Inspector](../.gitbook/assets/toolbar-right.png)

- **Essential** / **Studio** — how many controls you see ([next page](essential-studio.md))
- **Export** — Export Movie dialog
- **?** — MemoryString Help (**⌘/**)
- Inspector toggle — show or hide the right column (**⌥⌘I**)

Toolbar **+** (near the project name) is **Photos & Videos…**, **Music…**, and **Royalty-Free Library…**.

**View → Toggle Sidebar** (**⌃⌘S**) shows or hides the Library.

## Inspector clip bar

The bottom of the Inspector stays available on every tab: caption (or intro text), **Generate**, **Aa** (caption position / color / size), and trim / mute / volume / remove when a video or soundtrack is selected.
