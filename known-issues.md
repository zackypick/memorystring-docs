# Known Issues

As of **1.2.7**:

* Refractive Bubbles lens effect: bubbles can repeat the same pattern across slides, show the previous photo, freeze while scrubbing, or briefly turn black. Fixed for the next release.

Fixed in **1.2.4**:

* Import from Photos: album and people cover thumbnails stalling on first load in large Photos libraries.
* Large imports: importing several hundred assets at once spiking memory use.
* Large projects: Library and timeline feeling heavy on shows with many clips.

See [Fixed](fixed.md) for everything fixed in each release.
