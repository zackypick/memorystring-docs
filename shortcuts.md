# Keyboard shortcuts

Menu items also show their keys.

## Project

| Key | Action |
| --- | --- |
| **⌘N** | New project |
| **⌘O** | Open… |
| **⌘S** | Save |
| **⇧⌘S** | Save As… |
| **⌘W** | Close project (does not quit) |
| **⌘Q** | Quit |
| **⌘E** | Export Movie… |

Traffic-light close closes the window only — reopen from the Dock.

## Edit

| Key | Action |
| --- | --- |
| **⌘Z** / **⇧⌘Z** | Undo / Redo (**⌘Y** also Redo when not typing) |
| **⌘V** / **⌘C** | Paste / copy media (plain text while a caption or title field is focused) |
| **⌘⌫** | Delete selected media or music |
| **⌘D** | Set Duration… |
| **⌘1** / **⌘2** | Set Start Here / Set End Here |
| **⌘]** / **⌘[** | Rotate Right / Rotate Left |
| **⇧⌘]** / **⇧⌘[** | Flip Horizontal / Flip Vertical |

**Edit → Auto Caption N Untitled Slides** and **Edit → Sort by Date Taken** are in the menu (no extra keys beyond what the menu shows).

## View

| Key | Action |
| --- | --- |
| **⌃⌘S** | Toggle Sidebar |
| **⌥⌘I** | Show / Hide Inspector |
| **⇧⌘S** | Switch Essential / Studio |
| **⌘+** / **⌘-** / **⌘0** | Increase / Decrease / Default **UI** text size (not slide captions) |
| **⌥⌘+** / **⌥⌘-** | Timeline zoom in / out |

## Playback

| Key | Action |
| --- | --- |
| **Space** | Play / Pause (not while a text field is focused) |
| **←** / **→** | Nudge playhead |
| **⇧←** / **⇧→** | Larger steps |
| **⌘→** / **⌘←** | Next / Previous Slide |
| **⌥⌘←** | Go to Start |

## Help

| Key | Action |
| --- | --- |
| **⌘/** | MemoryString Help… |
| **⌘,** | MCP Server |

**Help → Show Walkthrough** replays the first-run tour. **Help → Report a Problem…** emails a sanitized crash package (stacks, Mac specs, breadcrumbs; no media filenames).
